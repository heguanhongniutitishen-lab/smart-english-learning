# Sprint 11 学生端 MVP 验收清单

> 范围：`sprint-11/student-playable-demo`、PR #11（draft）。本清单不代表已上线或批准合并。

## 已实现的验收场景

- [x] 无真实身份时仅使用 Demo；身份参数不完整时禁止假冒真实学习。
- [x] 真实学生读取当天计划、已审核发布的学习题目；真实答题由 API 判分，产生唯一作答记录。
- [x] 正常答题完成今日任务；错误题产生错误观察及待确认的错因候选。
- [x] 无独立审核题时不伪造确认题、不认定掌握、不触发个性化修复。
- [x] 真实错题可读取另一道已审核且知识点匹配的独立题，服务器判分、存证并关联待审查错因。
- [x] 学生请求不能直接提交 `Supports` / `Contradicts` 冒充错因验证。
- [x] 学生可读取自己的待审查证据状态，但看不到答案或内部原始证据。
- [x] 一次确认题提交遇到响应丢失时，刷新后用原答案、原请求编号恢复，不生成第二次作答。
- [x] 已成功保存的确认题再次进入首页时，可凭受身份与日期约束的本地线索重新查询**服务器证实**的待审查状态，不重新答题；服务端不可用时不假称成功。
- [x] 浏览器端 / API 的自动化用例覆盖权限边界、证据关联、重试、错误反馈和学习主线返回。

## 仍未满足的交付条件

- [ ] 错因证据判定规则经课程/教学负责人审核批准，明确独立证据对具体错因的 `Supports` / `Contradicts` 条件，并补齐反例。
- [ ] 在可信规则下，由服务端执行错因判定并安全生成、完成个性化修复任务；当前 **仅 PendingReview**。
- [ ] 正式账号认证、会话安全、真实测试学生与完整教材内容接入完成；URL 中的 `student` / `user` 仅为开发联调方式。
- [ ] 按真实用户验收脚本开展跨设备、断网、长时间退出、账号切换测试。
- [ ] 单独核验目标 Vercel 部署版本、运行环境与数据库迁移；GitHub CI 通过不等于线上部署通过。
- [ ] 审核 PR #11 并获得显式合并授权，才可合并。
